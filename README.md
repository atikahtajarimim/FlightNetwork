# Flight Network Explorer

Interactive U.S. flight-network explorer for the ECC3841 project.

## Run locally

From this directory:

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000/>.

## GitHub Pages

Enable GitHub Pages for the repository using the `main` branch and the repository root. The site will be available at:

```text
https://coskipy.github.io/FlightNetwork/
```

The explorer loads its data from `data/bts_route_network_1990_2026.csv`.
